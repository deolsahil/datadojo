Opening DataDojo the first time

DataDojo isn't signed by Apple or Microsoft yet, so your computer asks once. After that it opens like any app.

macOS shows a warning the first time:

  1. Open DataDojo from Applications and click Done on the warning.
  2. Open System Settings → Privacy & Security.
  3. Scroll down and click Open Anyway next to DataDojo, then confirm.

Windows SmartScreen may warn about an unrecognised app:

  1. Click More info.
  2. Click Run anyway.
  3. Follow the installer. DataDojo appears in the Start menu.

No warning on Linux:

  1. Extract the download.
  2. Run DataDojo/DataDojo. It opens in your browser.
PySpark problems need Java 17 (free from adoptium.net). Everything else works out of the box.
Desktop app

DataDojo lives on your computer

It runs real SQL, Python and Spark engines on your machine, so phones and tablets can't install it. Send yourself the link and grab it on a Mac, Windows or Linux computer.
